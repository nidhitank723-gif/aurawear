# AuraWear - Women's Fashion & Clothing Store

A clean, responsive, and elegant e-commerce frontend website built purely with **HTML5**, **CSS3**, and **Vanilla JavaScript**. Perfect for college project submissions and viva demonstrations.

---

## Features
- **Responsive Navigation**: Sticky header with brand logo, smooth navigation, live search bar, and cart drawer.
- **Hero Banner**: Engaging introduction with Call to Action buttons.
- **Categories Showcase**: Filterable product collections (Dresses, Tops & Tees, Ethnic & Kurtis, Jeans & Pants, Co-ord Sets).
- **Interactive Product Catalog**:
  - Live search by product name, category, or description.
  - Category filter tabs.
  - Detailed product cards with pricing, discounts, and ratings.
- **Shopping Cart Drawer**:
  - Add to bag functionality.
  - Real-time quantity adjustment (`+` / `-`) and item removal.
  - Dynamic total price calculation stored in `localStorage`.
- **Quick View Modal**: Click on any item to view high-resolution image, sizing options, and complete details.
- **About & Philosophy Section**: Highlights quality, breathable fabrics, and customer exchange policies.
- **Newsletter & Contact**: Subscription form and store contact information.

---

## Tech Stack
- **HTML5**: Semantic markup structure.
- **CSS3**: Responsive flexbox and grid layouts, Google Fonts (`Plus Jakarta Sans` & `Playfair Display`), smooth transitions.
- **JavaScript (ES6)**: Vanilla JS for DOM manipulation, live search, cart management, modal popups, and localStorage persistence.

---

## How to Run Locally

### Option 1: Direct in Browser
Simply double-click the `index.html` file to open and run it directly in any modern browser (Chrome, Edge, Firefox, Brave).

### Option 2: Using Any Local Server
You can also run a simple lightweight server:
```bash
# Using Python
python -m http.server 8000
```
Then open: `http://localhost:8000`
